# /hack:help — How to use Hack Kit

Show this, then add one line with the next command based on `.hackathon/STATE.md` if the file exists:

```
HACK KIT  ·  from problem statements to a locked, buildable idea

 FIND IT            SHAPE IT            BUILD & SELL IT
 1 /hack:start      4 /hack:users       9  /hack:plan
 2 /hack:decode     5 /hack:validate   10  /hack:verify  ⚖️
 3 /hack:pick  ⚖️    6 /hack:compete    11  /hack:pitch
                    7 /hack:stress     12  /hack:ship  → FINAL.pdf
                    8 /hack:lock  🔒

 ANYTIME   /hack:status · /hack:court <thing> ⚖️ · /hack:help
 FLAGS     --quick   faster, 6 jurors, shorter outputs

 ⚖️ = courtroom trial (prosecution · defense · 12 jurors · verdict)
 🔒 = idea freeze: after this, fixes go inside the core
```

Then show the quick start:
1. Before the statements are out: run `/hack:start` and fill in the brief.
2. When they're out: `/hack:decode` → `/hack:pick`.
3. Split the team: one person on `/hack:validate`, one on `/hack:compete`, one talking to people at the venue.
4. Lock at about 1.5 h: `/hack:stress` → `/hack:lock`.
5. Then `/hack:plan` → `/hack:verify` → build → `/hack:pitch` → `/hack:ship`.
