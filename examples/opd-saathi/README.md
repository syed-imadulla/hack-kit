# Example: OPD Saathi

A worked example of what Hack Kit produces, based on Syed Imadulla's real Round 1 idea for the Healthcare AI Agents track. The files are shortened. Numbers marked *target* are pilot goals, not results.

Run the compiler on this folder to see a sample final PDF:

```bash
python3 scripts/compile.py examples/opd-saathi/.hackathon
```

Files (v1.0 format):
- `.hackathon/STATE.md`: schema 2, with the decisions log and locked items
- `.hackathon/IDEAS.md`: directions explored, scores, rejected ideas
- `.hackathon/ASSUMPTIONS.md`: kill test and status
- `.hackathon/IMPROVE.md`: one improvement round, v1 → v2
- `.hackathon/CORE.md`: the locked idea (v2)
- `.hackathon/VERDICT.md`: a Hack Court 2.0 verdict (sample)
- `.hackathon/SUMMARY.md`: one page

The full set of files (statements, users, evidence, plan, pitch) comes in v1.2.
